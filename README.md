# PassForge

**Simulate. Study. Pass.**

Offline-first Flutter mock exam app scoped **only** to Philippine exams (PRC/CSC).

## Brand

| Token | Hex | Use |
|-------|-----|-----|
| Deep violet | `#2E1065` | Splash / adaptive icon / window |
| Mid violet | `#4C1D95` | Strong brand text / dark accents |
| Vivid violet | `#6D28D9` | Primary buttons / progress |
| Soft violet | `#C4B5FD` | Highlights / washes |
| White | `#FFFFFF` | Logo mark |

Exam accent colors (LET sky blue, PNLE green, etc.) stay distinct from brand violet.

## Coverage

LET · PNLE · CPALE · CELE · **CSE** · **ALE (Agriculture)** · CLE  

End-of-exam: simulated **75% pass mark**, pass/fail verdict, and passing stats.
